Read a file or directory inside the workspace. If the path does not exist, an error is returned (with similar-filename suggestions when available).

Usage:
- The filePath parameter can be a relative path from the workspace root or an absolute path inside the workspace.
- By default, this tool returns up to 2000 lines from the start of the file.
- The offset parameter is the 1-indexed line number to start from (1 = first line).
- To read later sections, call this tool again with a larger offset.
- Use the grep tool to find specific content in large files or files with long lines.
- If you are unsure of the correct file path, use the glob tool to look up filenames by glob pattern.
- Contents are returned with each line prefixed by its line number as `<line>: <content>`. For example, if a file has contents "foo\n", you will receive "1: foo". For directories, entries are returned one per line (without line numbers) with a trailing `/` for subdirectories.
- Any line longer than 2000 bytes is truncated.
- Call this tool in parallel when you know there are multiple files you want to read.
- Do NOT re-read a file you just created with `write` in this conversation unless an `edit` returned a mismatch, and never read large files like `index.html` in tiny sequential 40–80 line slices (default limit is 2000 lines / 100 KiB — read once in full if needed).
- This tool can read image files (PNG, JPEG, WebP, GIF up to 4 MB) and attach them directly to vision context.

Launch a specialized subagent to handle complex, multistep tasks autonomously.

When using the `task` tool, specify `subagent_type` to select the agent role (`general`, `explore`, `motion-designer`, `audio-director`, `qa-verifier`).

When NOT to use `task`:
- Reading a specific file or directory -> use `read` or `glob` directly.
- Searching for a symbol or pattern -> use `grep` directly.
- Editing 1-2 known files -> use `read` + `edit`/`write` directly.

Usage notes:
1. Launch independent subagents in parallel in one message when helpful.
2. Non-motion subagents run asynchronously in the background by default (`background: true`), returning immediately with `state: "running"` and delivering `<subagent-notification>` when complete. Pass `background: false` if you need a synchronous blocking wait. `motion-designer` always runs synchronously so scene renders never collide.
3. Each invocation starts fresh unless you pass `sessionID` (or `task_id`) from a prior `task` result to resume that child session.
4. Give clear, self-contained instructions including exact file paths and verification criteria.
